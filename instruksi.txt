- IMPORTANT -

Before running any commands, u need to make sure that the Python virtual environment is turned on.

Command:
source venv/bin/activate

-------------------------

Running the app:

I combined all necessary commands into a shell script so you can easily run the app.

Command:
./start_app.sh

you may then open http://localhost:5173/ in you chosen browser.
-------------------------

Optionals (Running files individually)

Running the server:

Command:
python server.py

Running the sample esp32 data stream (TESTING PURPOSES ONLY):

Commands:
cd test_client
python client.py
